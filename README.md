# cmsc315_unit2_discussion
Unit 2 Discussion
During this assignment, I learned how stacks and queues operate at a fundamental level and how their behaviors directly affect how applications manage data. Implementing the stack helped me understand how Last‑In‑First‑Out processing mirrors features like a phone’s undo history, where the most recent action is always the first one reversed. Working with the queue reinforced how First‑In‑First‑Out behavior supports systems such as a smartphone’s call history, where the earliest call appears first and newer calls are added to the end.

One challenge I encountered was handling edge cases, especially when pop or dequeue operations were performed on empty structures. I overcame this by adding clear conditional checks and returning helpful messages instead of allowing the program to crash. This made the program more robust and user‑friendly.

Overall, this assignment strengthened my understanding of how stacks and queues support predictable, reliable behavior in software. Seeing how these structures map directly to real‑world applications made the concepts easier to visualize and apply.
